# Source - Markdown-First Retrieval for Small Knowledge Vaults

## What this source is

Synthetic test article (marked as fictional test data in the source itself) arguing that a small
vault should start with curated navigation and text search before adding embeddings.

## Claims taken from it

- Curated index + wikilinks + text search should be tried before embeddings, below ~100 pages.
- Retrieval tooling should be added in response to measured failures, not up front.
- Markdown stays the source of truth even if a derived search index is added later.
- Suggests the benchmark method: 20 questions, record expected pages, measure retrieval.
