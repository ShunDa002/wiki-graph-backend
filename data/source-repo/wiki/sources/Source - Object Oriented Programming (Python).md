# Source - Object Oriented Programming (Python)

## What this source is

Notes covering the fundamentals of Object-Oriented Programming (OOP) in Python, focusing on class construction, object initialization, and data encapsulation compared to simpler data structures.

## Claims taken from it

- Classes act as blueprints for creating custom data types, allowing for more complex software design than built-in primitives.
- The `__init__` instance method acts as a constructor, allowing developers to standardize attributes and customize objects upon instantiation.
- Unlike dictionaries or tuples, classes enable data validation (often using `raise` to signal errors like `ValueError`) and behavioral encapsulation directly within the data structure.
- Tuples provide immutable collections of values, while Dictionaries provide mutable, semantically keyed associations.
