# Source - Tools

## What this source is

Notes defining what tools are in the context of Agentic AI, listing common examples, and explaining the standard tool calling workflow.

## Claims taken from it

- A Tool is an external function, API, database, or service that enables an AI agent to perform actions beyond text generation (e.g., search, calculate, execute code).
- The standard "Tool Calling" workflow consists of an 8-step process where the agent decides if a tool is needed, generates arguments, executes it, and incorporates the result.
