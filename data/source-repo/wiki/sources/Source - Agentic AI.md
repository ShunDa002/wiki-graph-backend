# Source - Agentic AI

## What this source is

Notes covering the key characteristics and components of Agentic AI, as well as an overview of asynchronous programming concepts in Python.

## Claims taken from it

- Agentic AI is characterized by being autonomous, goal-oriented, and having capabilities for planning, reasoning, adaptability, and context awareness.
- An Agentic AI framework consists of components like a Brain (LLM), Orchestrator, Tools, Memory, and Supervisor.
- Co-routine functions allow cooperative multitasking using keywords like `yield` or `await`, unlike subroutine functions which follow a strict caller-callee relationship.
