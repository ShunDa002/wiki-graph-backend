# Source - Langchain Ecosystem

## What this source is

Notes covering three main components of the LangChain ecosystem: LangSmith, LangServe, and LangGraph.

## Claims taken from it

- LangSmith is an LLMOps tool used for observability, debugging, and evaluating LLM apps and agents by recording execution traces.
- LangServe is used for deployment and creating APIs for LLM applications, utilizing FastAPI in the backend.
- LangGraph is a framework used to create individual agents and multi-agent systems.
