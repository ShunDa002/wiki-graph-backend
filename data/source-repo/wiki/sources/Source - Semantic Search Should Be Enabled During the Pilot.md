# Source - Semantic Search Should Be Enabled During the Pilot

## What this source is

Synthetic test article, marked in its own text as intentionally conflicting with another test
source. Argues embeddings should be created from day one of any pilot.

## Claims taken from it

- Semantic retrieval is claimed to be superior to curated indexes and full-text search
  unconditionally — no vault-size, vocabulary, cost, or maintenance qualifier is given.
- Rationale offered: users phrase questions differently from source wording, so lexical search
  can miss what semantic similarity would catch.
- Strong claim: a pilot without embeddings "cannot produce reliable answers" and is not a valid
  knowledge system.

## What it changed in the Wiki

- Created: [[Semantic Search Enablement Timing]]
- Contradicted: [[Markdown-First Retrieval]] — on when (if ever) embeddings are needed

## Not used

The source itself flags that it provides no benchmark, dataset, cost analysis, or size comparison,
and does not define "reliability." That absence of evidence is recorded on the concept page
directly rather than treated as a claim to cite.
