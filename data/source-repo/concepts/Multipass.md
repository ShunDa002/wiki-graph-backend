# Multipass

## Definition

Multipass is a command-line tool designed to quickly orchestrate, launch, and manage Ubuntu system virtual machines [[Source - Linux Commands and Vim Operations]].

## Basic Usage

- `multipass launch`: Provisions and boots a new Ubuntu VM.
- `multipass list`: Displays all currently installed and running VMs.
- `multipass <name>`: Opens a shell session inside the specified VM.
