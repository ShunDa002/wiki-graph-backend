# Source - Application Programming Interfaces

## What this source is

A conceptual overview of Application Programming Interfaces (APIs), highlighting the RESTful architectural paradigm.

## Claims taken from it

- An API is an entry point exposed by an application (as a function, class method, or network URL) allowing clients to execute corresponding logic and operate on data.
- Standardized API specifications (such as REST or RPC) are crucial for establishing consensus within development teams and reducing cooperation costs.
- REST (Representational State Transfer) is a prominent, language-agnostic architectural style tailored for web development and decoupled frontend/backend applications.
- RESTful APIs follow a "Resource-Oriented" paradigm:
  - The URL explicitly represents the data resource being acted upon (e.g., `/student/`).
  - HTTP methods dictate the action taken on that resource: POST (create), GET (read), PUT (complete modification), PATCH (partial modification), and DELETE (remove).
